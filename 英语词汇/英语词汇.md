# Part 1 开发调试英语（Debug English）


# 1. 报错基础词汇


| English   | 中文     | 解释                 |
| --------- | -------- | -------------------- |
| Error     | 错误     | 程序发生错误         |
| Exception | 异常     | 运行过程中出现的问题 |
| Warning   | 警告     | 不一定影响运行       |
| Failure   | 失败     | 操作没有成功         |
| Fatal     | 致命的   | 导致程序终止         |
| Critical  | 严重的   | 需要立即处理         |
| Traceback | 错误追踪 | 显示错误调用路径     |
| Stack     | 调用栈   | 函数调用关系         |
| Debug     | 调试     | 查找错误             |
| Bug       | 程序错误 | 软件缺陷             |
